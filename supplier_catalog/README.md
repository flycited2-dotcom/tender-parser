# Каталог поставщиков

Эта папка связывает найденные закупки с локальными прайсами производителей и
дистрибьюторов. Коммерческие прайсы не отправляются в GitHub: все файлы внутри
`supplier_catalog/private/` исключены из Git.

## Куда класть прайсы

Для каждого поставщика создайте отдельную папку:

```text
supplier_catalog/
  suppliers.json
  private/
    promet/
      inbox/
        Прайс_Промет_2026-07-13_дилер.xlsx
```

Поставщик и маски его файлов описываются в `suppliers.json`. Для добавления
нового поставщика скопируйте объект Promet, задайте уникальный `id`, название,
пути к файлам и категории тендеров, для которых этот прайс применим.

## Как пользоваться

Пересобрать закрытый индекс после добавления прайса:

```powershell
python -m tender_parser supplier-index
```

Найти товары по названию, модели или артикулу:

```powershell
python -m tender_parser supplier-search --query "шкаф архивный" --limit 10
```

В Telegram-боте доступна команда:

```text
/price стеллаж MS Standart
```

## Входящие прайсы

Доверенные адреса поставщиков перечисляются в `suppliers.json` в поле
`email_senders`. Пример ручного или автоматического импорта:

```powershell
python -m tender_parser supplier-import --file "C:\Downloads\price.xlsx" `
  --sender "prices@example.ru" --channel gmail
```

Принятые файлы сохраняются только в gitignored-каталоге
`supplier_catalog/private/<supplier>/inbox/`. Для каждого вложения записываются
канал, отправитель, время, SHA-256 и идентификатор сообщения. Повторный файл по
тому же хешу не дублируется. Неизвестные отправители попадают в
`private/quarantine/inbox/` и не участвуют в поиске.

Бот принимает пересланный прайс только в настроенном чате и только с явной
подписью поставщика, например `/pricefile promet`. Он не видит личные диалоги
пользователя и не может сам читать их. Поддерживаемые для автоматической
индексации форматы: XLSX/XLSM; CSV/PDF/ZIP/RAR сохраняются до появления
адаптера их структуры. Макросы не исполняются.

Во время обычного запуска тендерного агента подходящие позиции поставщиков
записываются в закрытый отчёт `exports/supplier_matches.json`. Оригинальный
прайс остаётся источником истины; индекс автоматически обновляется, если файл
заменён или добавлен новый.

## Требования к Excel

Заголовок может находиться не на первой строке. Импортёр ищет колонки
`Артикул`, `Наименование` и цену. Приоритет цены:

1. `Цена закупки дил`, `Дилерская цена` или `Закупочная цена`;
2. `Розничная цена`;
3. общая колонка `Цена`/`Стоимость`.

Для сложных технических заданий используйте в запросе ключевые размеры,
модель и серию — например `шкаф архивный 1850 850` или `AIKO SL-185/2`.
