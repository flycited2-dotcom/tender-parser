# Сбор и доставка после сбоев

Исключение независимого источника, в том числе MemoryError, записывается в
диагностику как error и не отменяет результаты остальных источников. Это не
гарантия восстановления при системном исчерпании памяти или завершении Windows.
Ответы РосТендера читаются потоково с пределом 8 MiB распакованных данных.

Excel загружается в Telegram с увеличенным таймаутом. Только ConnectTimeout
(соединение не установлено) автоматически повторяется до трёх попыток.
После трёх неудач файл остаётся в exports, описание задания — рядом, в
`.telegram_pending`. Токен в очереди не сохраняется. ReadTimeout и прочие
неопределённые исходы не повторяются автоматически во избежание дубликатов.

Повторить недоставленные файлы без сбора сайтов:

```powershell
.\.venv\Scripts\python.exe -m tender_parser.delivery_retry --base-dir .
```

Очередь также проверяется перед очередным штатным ежедневным сбором. Получатель
и размер/дата файла сверяются; изменённый файл и смена чата требуют ручной проверки.
Расписание обхода площадок не меняется.
