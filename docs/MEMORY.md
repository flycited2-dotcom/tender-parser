# Project Memory

Дата обновления: 2026-05-29

## Назначение

Проект `Парсинг_тендеры` - Windows-парсер публичных закупок и тендеров. Публичный режим работает без авторизации: сначала использует Rostender как широкий открытый источник, а RTS-market оставлен вторым источником на случай доступности публичных страниц.

## Ключевые решения

- Запуск для пользователя: двойной клик по `Запустить_парсер.bat`.
- Ручной запуск: `python -m tender_parser run`.
- История хранится в `data/tenders.db`.
- Текущая выгрузка создается в `exports/tenders_YYYY-MM-DD.xlsx`.
- CRM-заготовка создается в `exports/latest.json`.
- `data/` и `exports/` не коммитятся, потому что это локальные рабочие артефакты.
- Excel содержит листы `Подходящие`, `На проверку`, `Отсеянные`.
- Если все публичные источники RTS возвращают captcha/rate-limit или сетевые ошибки, старые Excel/JSON не перезаписываются.
- Обычный запуск сейчас использует `CompositeSource([RostenderSource(), RtsPublicSource()], stop_after_first_success=True)`, чтобы не тратить минуту на RTS-ошибки, если Rostender уже дал результат.

## Фильтры

- Минимальная сумма: от `30 000` рублей.
- Только актуальные процедуры: дедлайн подачи должен быть позже текущего времени.
- Регионы: Симферополь, Севастополь, Республика Крым, Крым, Запорожская область, Херсонская область.
- Интересующие категории: компьютерная техника и периферия, климатическая техника, бытовая техника, канцелярия/офис, электротехника и оборудование.
- Стоп-темы: ГСМ, топливо, дизель, бензин, капитальный ремонт, строительство/дороги/асфальт/ПСД, лекарства и лекарственные препараты.
- Дополнительные broad-запросы: оргтехника, офисная техника, расходные материалы, заправка картриджей, климатическое оборудование, электротовары, металлическая мебель, шкафы.
- Поиск идет не только по категориям, но и по региональным словам, чтобы ловить закупки с нестандартными названиями.
- Для Rostender задан отдельный список запросов `ROSTENDER_SEARCH_QUERIES`: МФУ, принтеры, оргтехника, картриджи, расходники, кондиционеры, канцелярия, сейфы/стеллажи по Крыму, Севастополю, Херсонской и Запорожской областям.
- По дополнительным ЭТП создано исследование `docs/etp_source_research_2026-05-29.md`. Приоритет расширения источников: ЭТП ГПБ RSS/API, B2B-Center HTML, Tender.Pro API, Торги82 HTML, затем Фабрикант.

## Текущие ограничения

- Личный кабинет RTS-Tender не подключен.
- Капча и закрытые разделы не обходятся.
- HTML-парсер покрыт одной fixture-формой публичной таблицы; при изменении верстки RTS может потребоваться обновить selectors.
- Матчинг однословных категорий учитывает границы слов, чтобы не ловить `монитор` в `мониторинг` и `провод` в `трубопровод`.
- Следующий крупный шаг - расширение источников за пределы RTS: первым делом ЭТП ГПБ через RSS/API и B2B-Center через публичный HTML. Отдельный авторизованный source для личного кабинета RTS остается полезным, но не первым по отдаче.
