# RTS Cabinet Browser Mode

## Что это

Режим собирает закупки из личного кабинета RTS-Tender через отдельный профиль Google Chrome. Парсер не знает ваш пароль, PIN, сертификат или ЭЦП. Вы входите вручную, а скрипт читает видимую страницу выдачи и передает карточки в общий отчет.

Этот режим не обходит вход, CAPTCHA, платные API или блокировки. Если RTS просит войти снова, нужно вручную повторить вход в открытом Chrome-профиле.

## Первый запуск

1. Запустите `Открыть_RTS_кабинет_Chrome.bat`.
2. В открывшемся Chrome войдите в RTS-Tender вручную.
3. Откройте страницу поиска или реестра закупок.
4. Поставьте фильтры RTS: период, статус, регион, ключевые слова.
5. Запустите `Собрать_RTS_кабинет.bat`.

## Где отчет

После сбора смотрите:

- `exports/latest.html` - удобный ручной отчет;
- `exports/latest.json` - очередь для CRM;
- `exports/new_tenders.json` - впервые увиденные подходящие закупки;
- `exports/run_report.json` - состояние источника `rts-cabinet`.

## Если просит войти снова

Откройте `Открыть_RTS_кабинет_Chrome.bat`, войдите заново и повторите сбор. Если в `run_report.json` у `rts-cabinet` статус `blocked`, значит RTS показал вход, CAPTCHA или защитную страницу.

## Безопасность

Профиль Chrome хранится локально в `browser_profiles/rts_chrome` и не коммитится в Git. Chrome запускается с debug endpoint только на `127.0.0.1:9222`; не используйте этот профиль на общей машине или с открытым удаленным доступом.
