# Публичный источник ТЭК-Торг

Источник `tektorg` читает официальный открытый SOAP API ТЭК-Торг без токена,
личного кабинета и электронной подписи:

- [описание API](https://api.tektorg.ru/procedures);
- [WSDL](https://api.tektorg.ru/procedures/wsdl);
- endpoint: `https://api.tektorg.ru/procedures/soap`.

По умолчанию опрашиваются основные закупочные секции `44fz`, `zakupki`,
`market`, `interrao` и `nornikel`. Секции продажи имущества не включены. Набор
можно изменить в локальном `.env`:

```dotenv
TEKTORG_SECTION_CODES=44fz,zakupki,market,interrao,nornikel
TEKTORG_LOOKBACK_HOURS=48
TEKTORG_PAGE_SIZE=100
TEKTORG_MAX_PAGES_PER_SECTION=10
TEKTORG_TIMEOUT_SECONDS=60
TEKTORG_TARGET_ONLY=1
```

Сначала забирается короткая выдача обновлённых процедур, затем локально
остаются только Республика Крым, Севастополь, Запорожская и Херсонская области.
Ключевые слова применяет общий фильтр после сбора. Это позволяет не потерять
новую товарную категорию из-за слишком узкого поискового запроса.

Из ответа сохраняются прямая карточка ТЭК-Торг, номер площадки, номер ЕИС,
предмет и сумма лотов, срок, документы, заказчик, ИНН, адрес, публичные e-mail,
телефон и контактное лицо. Контакты переносятся в лист потенциальных заказчиков
только в пустые поля и не заменяют значения, уже проверенные вручную.

Источник не выполняет вход, не выбирает сертификат, не подписывает документы и
не обходит CAPTCHA. Ошибка ТЭК-Торг отражается отдельной строкой здоровья и не
останавливает остальные источники.
