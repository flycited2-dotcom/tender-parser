# Официальная региональная XML-выгрузка ЕИС

Источник `eis-regional-xml` читает публичную массовую выгрузку 44-ФЗ для четырёх
целевых регионов: Республики Крым, Севастополя, Запорожской и Херсонской
областей. Это независимый контур к HTML-поиску ЕИС: изменение вёрстки поиска не
ломает разбор XML.

Основной источник `eis-zakupki` параллельно читает живую региональную выдачу
44-ФЗ и 223-ФЗ по тем же четырём регионам. Теперь каждая карточка сразу получает
структурированные поля официального номера, прямого URL, закона и уверенности
источника; XML является дополнительным независимым контуром, а не заменой HTML.

Официальные основания:

- [назначение и владелец ЕИС — Федеральное казначейство](https://roskazna.gov.ru/gis/eis-zakupki-gov-ru);
- [требования к актуальным форматам 44-ФЗ — ЕИС](https://zakupki.gov.ru/epz/main/public/document/view.html?sectionId=6&pageNo=1&categories=FZ44&_categories=on);
- массовая выгрузка: `ftp://free:free@ftp.zakupki.gov.ru/fcs_regions/`.

## Статус канала

По умолчанию feature flag выключен. ЕИС официально сообщила, что после
01.07.2024 доступ к FTP закрывается, а массовая отдача переводится на сервисы
отдачи информации (СОИ), подключаемые по актуальным требованиям ЕИС:
[сообщение оператора от 23.01.2024](https://zakupki.gov.ru/epz/main/public/news/news_preview.html?newsId=34208).

Поэтому этот модуль больше не считается живым сетевым источником. Он остаётся
для безопасной обработки уже скачанных архивов и как готовый XML-парсер для
будущего адаптера СОИ. Не следует включать его только ради попыток подключиться
к закрытому FTP. Если нужно обработать локальные архивы, в `.env` установить:

```dotenv
EIS_XML_ENABLED=1
EIS_XML_STATE_PATH=data/eis_regional_xml_state.json
EIS_XML_IMPORT_DIR=imports/eis_xml
```

В коде профиля источник создаётся через feature flag:

```python
from tender_parser.sources.eis_regional_xml import EisRegionalXmlSource

EisRegionalXmlSource.from_env(
    state_path=data_dir / "eis_regional_xml_state.json",
    import_dir=base_dir / "imports" / "eis_xml",
)
```

В профиле он стоит перед HTML-источником `EisZakupkiSource`. При выключенном
флаге health имеет статус `skipped`, сетевое соединение не открывается. Живой
сбор продолжает работать через публичную региональную HTML-выдачу 44-ФЗ и
223-ФЗ; подключение СОИ с выдаваемыми в ЕИС реквизитами выполняется отдельно.

## Ручной импорт при недоступности FTP

Скачанные с официальной выгрузки `.zip`, `.xml.zip` или `.xml` можно положить в
папку региона без распаковки:

```text
imports/eis_xml/
├── Krim_Resp/
├── Sevastopol/
├── Zaporozhskaja_obl/
└── Hersonskaja_obl/
```

Допускаются также папки с русскими каноническими названиями. Файлы не удаляются
и не перемещаются. Checkpoint не даёт повторно обрабатывать неизменённый файл;
изменение размера или времени модификации образует новую версию.

## Устойчивость и ограничения

- одновременно читаются `currMonth` и, в первые семь дней месяца, `prevMonth`;
- не более 8 новых архивов на регион и 24 архивов за запуск;
- один архив — до 25 МБ, суммарная загрузка — до 100 МБ;
- один XML — до 12 МБ, распакованные данные — до 80 МБ;
- не более 2 000 членов ZIP, степень сжатия ограничена;
- ZIP читается в памяти без извлечения путей на диск;
- XML с `DOCTYPE` или `ENTITY` отклоняется;
- checkpoint записывается атомарно только после успешного разбора архива;
- последний успешный снимок возвращается и при отсутствии новых файлов;
- при частичной недоступности регионов/архивов health — `partial`, снимок
  сохраняется; при полной недоступности без кеша — `error`.

Парсер поддерживает XML с пространствами имён и варианты TFF по локальным
именам полей. Набор полей дополнительно сверен с переданными схемами TFF 16.2.2
и 16.2.4 (`purchaseNumber`, `purchaseObjectInfo`, `maxPrice`,
`collectingEndDate`, `collectingEndDT`, `docPublishDate`, `docPublishDTInEIS`,
`deliveryPlace`, `customerInfo/fullName`). Незнакомые документы без номера
пропускаются. Периодически TFF меняется, поэтому после обновления «Альбома ТФФ» необходимо
добавлять соответствующий обезличенный XML fixture и тест до расширения списка
полей.
