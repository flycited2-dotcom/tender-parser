# Универсальная маршрутизация товарного подбора

## Главное правило

Агент не хранит закрытый список товарных категорий и не начинает любую позицию с I-T-P.
Для каждой строки ТЗ первым вызывается `route_product_search`. Маршрутизатор использует
смысл запроса и фактические ответы подключённых каталогов.

## Контур

1. Нормализация позиции: назначение, модель/артикул, обязательные характеристики,
   количество, комплектность и работы.
2. Семантическая проверка специализированных собственных хабов. Сейчас подключён
   климатический хаб; новые хабы добавляются как источники со своим предикатом применимости.
3. Универсальный поиск по всем частным прайсам. Возможности поставщика выводятся из
   разделов и номенклатуры самого прайса, поэтому новый вид товара не требует изменения
   инструкции агента.
4. Проверка широкого закрытого каталога I-T-P.
5. Проверка характеристик по официальным материалам производителя.
6. Открытый рынок и расширение выборки до 5, целевым образом до 10 вариантов/каналов.
7. Подготовка запросов поставщикам; отправка только после подтверждения владельца.

Пустой ответ или ошибка одного источника не останавливают остальные этапы.

## Почта и MCP

Почтовый пароль не передаётся в MCP и не используется во время каждого тендерного запроса.
На VPS отдельный `cf-mail.timer` безопасно синхронизирует разрешённых отправителей через IMAP:

`Gmail -> IMAP sync -> отдельные версионные XLSX-слоты -> read-only MCP -> тендерный агент`.

MCP читает только локальный приватный индекс. Для каждого письма сохраняются исходный
отправитель, тема, Message-ID, UID, дата, имя вложения и архивная версия. Один поставщик
не может затереть прайс другого. Цена прайса не считается подтверждением наличия.

## Журнал маршрута

По каждой позиции итог обязан показывать:

- распознанное назначение;
- все вызванные источники и статусы `matched`, `empty`, `rejected`, `error` или `unavailable`;
- выбранный первичный источник;
- причину перехода к следующему источнику;
- необходимость производителя/открытого рынка;
- точку ручного вмешательства владельца.
