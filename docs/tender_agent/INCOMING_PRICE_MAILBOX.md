# Входящий ящик прайсов поставщиков

## Назначение

`flycited@gmail.com` — дополнительный входящий адрес для прайс-листов и коммерческих предложений.
Исходящие запросы поставщикам по-прежнему отправляются только с `termoark@gmail.com`.

## Рекомендуемое подключение

В текущем подключении Gmail авторизован `termoark@gmail.com`. Чтобы одновременно сохранить этот
ящик для исходящих писем и получать прайсы из `flycited@gmail.com`, настройте в Gmail автоматическую
пересылку входящих прайсов с `flycited@gmail.com` на `termoark@gmail.com`:

1. Откройте Gmail под `flycited@gmail.com`.
2. Перейдите в «Настройки» → «Все настройки» → «Пересылка и POP/IMAP».
3. Добавьте адрес пересылки `termoark@gmail.com`.
4. Подтвердите пересылку из письма, поступившего на `termoark@gmail.com`.
5. Создайте фильтр только для писем поставщиков или писем с прайсами и включите действие
   «Переслать на `termoark@gmail.com`».

Не рекомендуется безусловно пересылать всю личную почту. Безопасный фильтр можно строить по
проверенным отправителям, теме «прайс»/«price» и наличию вложений. После пересылки агент должен
использовать исходного отправителя письма для регистрации поставщика.

## Статус автоматизации

На VPS работает `cf-mail.timer`: он синхронизирует XLSX-вложения только от разрешённых
отправителей, хранит отдельный версионный слот для каждого поставщика/файла и передаёт их в
read-only каталог. Тендерный MCP ищет по этому каталогу через `search_private_supplier_prices`
и включает его в общий `route_product_search`.

Почтовые пароли и одноразовые коды не передаются агенту и MCP. Цена из письма является первичным
ориентиром; наличие, срок и актуальность перед заявкой подтверждаются поставщиком.
