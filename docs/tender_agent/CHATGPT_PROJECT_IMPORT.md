# Перенос материалов из проекта ChatGPT «Тендеры ТЗ»

Codex в текущем локальном проекте не получает автоматически память, инструкции и файлы другого проекта ChatGPT. Надежный рабочий вариант — один раз выгрузить нужные источники и хранить локальную рабочую копию.

## Рекомендуемая структура

```text
knowledge_base/
  legal/
    44-fz/
    223-fz/
    national-regime/
  company/
    ooo-tlt/
    ip/
  templates/
    commercial-offers/
    supplier-requests/
    tender-forms/
  examples/
```

Папка `knowledge_base/` исключена из Git, поскольку в ней будут уставные, персональные и коммерческие документы.

## Как перенести файлы

1. Открыть проект «Тендеры ТЗ» в ChatGPT.
2. В списке источников проекта открыть нужный файл и скачать его.
3. Если файлы доступны в ChatGPT Library, можно выбрать несколько файлов и скачать их одной операцией.
4. Разложить файлы по папкам `knowledge_base/` согласно структуре выше.
5. Не переносить устаревшие дубли без даты редакции. Для нормативных документов в имени файла указывать дату актуальности.

Экспорт всех данных ChatGPT через `Settings → Data controls → Export` можно использовать как резервный путь для истории разговоров. Для рабочей базы он менее удобен: экспорт содержит общую историю и может готовиться несколько дней.

## Состояние переноса на 15.08.2026

Из проекта ChatGPT `Тендеры_ТЗ_КП` перенесена рабочая часть библиотеки:

- эталонная инструкция по генерации КП;
- три шаблона/эталона КП;
- таблица источников «Библия тендерного специалиста»;
- справочник ОКПД;
- регистрационные документы, карточки и выписки ООО «ТЛТ» и ИП Гуриненко.

Паспорта, архивы и договоры аренды намеренно не включены: для базового тендерного контура они избыточны и содержат персональные данные. Исходные `.doc`-карточки сохранены, а для полнотекстового поиска рядом созданы копии `.docx`.

Нормативные PDF из другого аккаунта ChatGPT не использовались как источник истины. Вместо них 16.08.2026 сформирован локальный комплект официальных документов ЕИС с идентификаторами источников, датами редакций и контрольными суммами. Он обновляется скриптом `Обновить_законы_ЕИС.ps1`. Два несводных файла ЕИС (ПП РФ № 60 и № 1042) исключены из активной базы до появления действующей консолидированной редакции: статичный исходный текст нельзя считать актуальным правом.

## Что будет после переноса

- создадим реестр документов с названием, типом, датой и контрольной суммой;
- отделим постоянные документы компании от документов конкретной закупки;
- определим актуальные и архивные редакции нормативных материалов;
- подключим шаблоны коммерческого предложения и запроса поставщику;
- добавим проверку комплектности ООО и ИП;
- исключим передачу секретов и персональных данных во внешние поисковые запросы.

## Локальный MCP-мост

После переноса файлы доступны Codex через read-only MCP-сервер `tender-knowledge`. Он предоставляет четыре инструмента:

- проверка состояния базы;
- список документов;
- полнотекстовый поиск;
- чтение выбранного документа.

Сервер не входит во второй аккаунт ChatGPT, не читает cookies и не использует закрытые внутренние API. Его источник — только локальная папка `knowledge_base/`, которую контролирует владелец.
