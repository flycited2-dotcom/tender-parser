# Парсер закупок и тендеров

Парсер ищет публичные актуальные закупки по заданным категориям, фильтрует их по регионам, сумме от 30 000 рублей и стоп-темам, сохраняет историю в SQLite и выгружает Excel.

## Запуск

Двойной клик по файлу:

```text
Запустить_парсер.bat
```

После завершения откроется папка `exports`.

## Результаты

- `data/tenders.db` - локальная история закупок.
- `exports/tenders_YYYY-MM-DD.xlsx` - Excel с листами `Подходящие`, `На проверку` и `Отсеянные`.
- `exports/latest.json` - JSON для будущей CRM с подходящими закупками и кандидатами на ручную проверку.
- Основной публичный fallback-источник: `rostender.info`, потому что публичный RTS часто возвращает captcha/rate-limit.
- Исследование следующих ЭТП для подключения: `docs/etp_source_research_2026-05-29.md`.

## Ручной запуск

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m tender_parser run
```

## Ограничения первой версии

- Работает только с публичными страницами без авторизации.
- Публичный режим проверяет несколько RTS-market источников: Rosatom, общий RTS-market, Симферополь и Ялта.
- Если RTS недоступен, парсер использует Rostender по заранее заданным регионально-категорийным запросам.
- Не подает заявки автоматически.
- Не обходит капчу и закрытые разделы; если RTS блокирует все публичные источники, старый отчет не перезаписывается.
- Личный кабинет RTS-Tender нужно подключать отдельным режимом.
